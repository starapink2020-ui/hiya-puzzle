هيا نركب البازل! — نسخة PWA أولية
==================================

محتويات المجلد:
- index.html: اللعبة
- manifest.json: إعدادات التثبيت على الشاشة الرئيسية
- service-worker.js: تخزين الملفات الأساسية للعمل دون إنترنت
- icons/: أيقونات التطبيق

طريقة النشر المجاني عبر GitHub Pages:
1) سجّلي الدخول إلى GitHub وأنشئي مستودعًا جديدًا (Repository) باسم hiya-puzzle.
2) ارفعي محتويات هذا المجلد كلها إلى جذر المستودع، بحيث يكون index.html في الصفحة الرئيسية للمستودع.
3) من Settings > Pages اختاري النشر من الفرع main والمجلد /(root)، ثم Save.
4) انتظري حتى يظهر رابط الموقع HTTPS.
5) افتحي الرابط في Safari على الآيفون أو الآيباد.
6) اضغطي زر المشاركة، ثم Add to Home Screen / إضافة إلى الشاشة الرئيسية، ثم Add.
7) افتحي التطبيق مرة وهو متصل بالإنترنت حتى تُخزّن الملفات، ثم جرّبيه بعد تفعيل وضع الطيران.

ملاحظات مهمة:
- يحتاج النشر الأول إلى الإنترنت، وبعد تحميل اللعبة بنجاح يمكن فتحها دون إنترنت.
- رفع الصور يعمل محليًا داخل اللعبة؛ الصور التي تختارينها ليست مضمونة الحفظ بعد إغلاق اللعبة أو إعادة تحميلها.
- إذا عدّلتِ الملفات لاحقًا، افتحي اللعبة مع الإنترنت لتصل النسخة الجديدة.
- العمل دون إنترنت يعتمد على أن يكتمل تحميل اللعبة مرة واحدة وأن يسمح Safari بتخزينها.
